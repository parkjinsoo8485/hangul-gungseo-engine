
# Jong_T1_ㅈ 와 Jong_T2_ㅈ 분석

## 종성 ㅈ의 표준 획순 (국립국어원)

ㅈ의 획순:
1. 위 가로획 (좌→우) - "一"형 (가장 위에 위치)
2. 왼쪽 빗금 (오른쪽 상단 → 왼쪽 하단) - "丿"형
3. 오른쪽 빗금 (왼쪽 중단 → 오른쪽 하단) - 또는 꺾임

## Jong_T1_ㅈ 데이터 (HanziWriter 좌표, y가 클수록 위)

- Stroke 0: start=(334,379), maxY=386 → 가로획 (y=379~386)
- Stroke 1: start=(568,398), maxY=398 → **y=398이 가장 높음! (1번이 더 위)**
- Stroke 2: start=(558,336), maxY=336

## 문제 파악

Stroke 1의 시작점 (568,398)이 Stroke 0의 시작점 (334,379)보다 y값이 높음(398 > 379).
이것이 "가장 위에 있는 획이 1번(0-indexed)"으로 판별되는 이유.

## 그런데 이것이 진짜 오류인가?

ㅈ의 실제 구조:
- 위 가로획: 획 전체가 대략 y=386~379 수준
- 왼쪽 빗금: 시작점이 (568, **398**) -> 가로획의 오른쪽 끝 부분에서 시작 -> 정상!

왜냐하면 왼쪽 빗금(2획)은 가로획(1획)이 완성된 후, 가로획의 **오른쪽 끝** 위에서 시작하기 때문.
실제로 시작 y=398이 가로획의 maxY=386보다 약간 위에 있는 것은 자연스러운 궁서체 붓 운필 형태.

## 결론: 이것도 오탐

ㅈ의 2획(왼쪽 빗금)이 1획(가로획) 보다 약간 높은 y값에서 시작하는 것은
궁서체에서 "기필(起筆)" 위치가 가로획의 끝에서 시작하기 때문에 정상.

검사 알고리즘의 "첫 획이 가장 위에 있어야" 규칙이 너무 단순함.
실제로는 ㅈ의 획순이 "1획 가로 → 2획 좌하빗금 → 3획 우하빗금" 순서가 맞음.
